# Bank Management System (C++)

## Description
C++ console application to manage bank accounts using OOP and file handling.

## Features
- Create account
- Deposit money
- Withdraw money
- Check balance
- Store records in file

## Technologies Used
- C++
- File Handling
- OOP

## How to Run
g++ main.cpp -o app
./app
